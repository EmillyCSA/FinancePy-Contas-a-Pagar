# 💰 FinancePy

Sistema de gerenciamento de contas a pagar desenvolvido em **Python** com **SQLite**.

O projeto foi criado com o objetivo de praticar lógica de programação, organização de código, manipulação de banco de dados e operações CRUD, simulando funcionalidades presentes em sistemas financeiros reais.

---

## 🚀 Funcionalidades

- ✅ Cadastro de contas
- ✅ Listagem de contas
- ✅ Edição de contas
- ✅ Marcar conta como paga
- ✅ Exclusão de contas
- ✅ Resumo financeiro
- ✅ Validação de ID para atualização e exclusão de contas

---

## 📊 Resumo Financeiro

O sistema apresenta um resumo contendo:

- 📋 Total de contas cadastradas
- 💰 Valor total das contas
- ✅ Quantidade de contas pagas
- 🕒 Quantidade de contas pendentes
- 💸 Valor total pendente

## ▶️ Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/FinancePy-Contas-a-Pagar.git
```

2. Entre na pasta do projeto:

```bash
cd FinancePy-Contas-a-Pagar
```

3. Execute o programa:

```bash
python main.py
```
